# 客户记录管理技能

## 何时使用

当用户请求以下任一场景时使用此技能：
- 添加新客户
- 查看客户列表
- 更新客户信息
- 删除客户记录

## 工作流程

1. **提取客户信息** - 从用户消息中提取客户姓名、电话等
2. **数据库操作** - 执行 CRUD 操作
3. **返回结果** - 确认操作成功

## 输出格式

- 客户姓名
- 联系方式
- 养殖类型
- 养殖规模

## 错误处理

- **客户已存在**: 提示用户
- **信息不完整**: 询问缺失信息

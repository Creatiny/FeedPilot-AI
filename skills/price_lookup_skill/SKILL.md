# 原料价格查询技能

## 何时使用

当用户请求以下任一场景时使用此技能：
- 询问"今天玉米价格"
- 询问"原料价格查询"
- 询问"豆粕多少钱"
- 查询多个原料价格

## 工作流程

1. **提取原料名称** - 从用户消息中提取要查询的原料
2. **查询数据库** - 从价格表获取最新价格
3. **返回结果** - 格式化输出价格信息

## 输出格式

- 原料名称
- 价格（元/吨）
- 价格日期
- 数据来源

## 错误处理

- **价格不存在**: 返回友好提示
- **原料名称模糊**: 询问用户确认

## 2. 功能说明

### 2.1 配方成本计算

#### 使用场景

- 想知道某个配方的成本
- 对比不同配方的成本
- 优化配方降低成本

#### 使用方法

**示例 1：计算已知配方成本**
```
你：计算保育料 1 号的成本
Bot: 正在计算配方成本...

📊 保育料 1 号 成本计算结果

💰 成本汇总
• 每吨成本：3500.50 元
• 每公斤成本：3.50 元

📦 成分明细
1. 玉米 (60%) - 1680.00 元 (48.0%)
2. 豆粕 (25%) - 1050.00 元 (30.0%)
3. 鱼粉 (5%) - 450.00 元 (12.9%)
4. 预混料 (10%) - 320.50 元 (9.1%)

💡 成本优化建议
• 玉米占比最高，可关注玉米价格波动
• 鱼粉成本占比较高，可考虑替代原料
```

**示例 2：创建新配方并计算**
```
你：创建一个新配方"育肥料 2 号"
Bot: 好的，请告诉我配方成分和比例...

你：玉米 65%，豆粕 20%，预混料 15%
Bot: ✅ 配方"育肥料 2 号"创建成功！

正在计算成本...
💰 每吨成本：3280.00 元
```

## 4. 常见问题

### Q1: 如何创建新配方？

**答**：直接告诉 Bot 你想创建配方，Bot 会引导你输入成分和比例。

```
你：我想创建一个新配方
Bot: 好的，请告诉我：
     1. 配方名称
     2. 适用阶段（保育/育肥/母猪）
     3. 成分和比例

你：育肥料 1 号，育肥阶段，玉米 65%，豆粕 20%，预混料 15%
Bot: ✅ 配方创建成功！
```

### Q2: 价格数据从哪里来？

**答**：价格数据来自 Barchart API，每天更新。如果 API 不可用，会使用最近 7 天的缓存数据。

### Q3: 我的数据会泄露吗？

**答**：不会。所有数据都存储在您的私有数据库中，其他用户无法访问。数据库使用 `owner_open_id` 进行严格隔离。

### Q4: 支持哪些动物类型？

**答**：目前支持：
- 🐷 猪（保育/育肥/母猪）
- 🐔 鸡（肉鸡/蛋鸡）
- 🐮 牛（肉牛/奶牛）
- 🐑 羊

### Q5: 如何优化配方成本？

**答**：Bot 会提供成本优化建议：
1. 识别成本占比最高的原料
2. 建议替代原料
3. 提供价格趋势分析

```
你：如何降低保育料 1 号的成本？
Bot: 💡 成本优化建议

🔍 成本分析
• 玉米占比 60%，成本占比 48%
• 鱼粉占比 5%，成本占比 12.9%

💡 优化建议
1. 玉米价格波动较大，建议关注市场行情
2. 鱼粉成本较高，可考虑使用豆粕替代部分鱼粉
3. 批量采购可获得更优惠价格

预计可降低成本：5-8%
```

# 营养分析技能

## 何时使用

当用户请求以下任一场景时使用此技能：
- 分析配方营养成分
- 对比 NRC 标准
- 优化营养配比
- 检查营养是否达标

## 工作流程

1. **获取配方数据** - 从数据库获取配方成分
2. **计算营养含量** - 计算粗蛋白、氨基酸等
3. **对比标准** - 与 NRC 标准对比
4. **返回结果** - 输出分析报告

## 输出格式

- 营养成分列表
- NRC 标准对比
- 达标情况
- 优化建议

## 错误处理

- **配方不存在**: 提示用户
- **数据不完整**: 询问缺失信息

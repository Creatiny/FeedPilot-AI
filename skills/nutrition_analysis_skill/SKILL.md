# 营养分析技能

## ⚠️ 重要规则

- ❌ **禁止**给用户任何 shell/SQL/Python 命令
- ❌ **禁止**说"运行这个命令查询..."
- ✅ **必须直接调用技能**获取数据并返回结果

## 何时使用

- 分析配方营养成分
- 对比 NRC 标准
- 优化营养配比
- 检查营养是否达标

## 工作流程

1. 调用数据库查询技能获取配方成分
2. 计算营养含量
3. 对比 NRC 标准
4. 直接输出分析报告

## 输出格式

- 营养成分列表
- NRC 标准对比
- 达标情况
- 优化建议

## 错误处理

- 配方不存在：提示用户
- 数据不完整：询问缺失信息
- 技能失败：道歉并建议重试，**不要**给命令

def _extract_customer_name(self, message: str) -> Optional[str]:
    patterns = [r'customer\s+([A-Za-z]+)', ...]  # ❌ 只匹配字母

**修复建议**:
```python
def _extract_customer_name(self, message: str) -> Optional[str]:
    patterns = [r'customer\s+([A-Za-z\s]+)', ...]
    for pattern in patterns:
        match = re.search(pattern, message, re.IGNORECASE)
        if match:
            name = match.group(1).strip()
            if len(name) > 100:  # ✅ 长度限制
                raise ValueError("Customer name too long")
            return name
    return None
```
